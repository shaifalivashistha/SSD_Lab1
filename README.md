#SSD LAB 1 - Student Portals

## Description
A simple command-line Python application to allow students to log in and access their profile, dashboard, and settings.

## Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

## Setup Instructions
1. Clone this repository:
   ```
   git clone https://github.com/shaifalivashistha/SSD_Lab1.git
   ```
2. Navigate into the project folder:
   ```
   cd SSD_Lab1
   ```

## Running the Application
```
python main.py
```
Follow the on-screen prompts to log in and access your profile, dashboard, or settings.

## Project Structure
- `main.py` - Entry point of the application
- `login.py` - Handles user authentication
- `profile.py` - Manages user profile data
- `dashboard.py` - Displays user dashboard
- `settings.py` - Manages user settings

## Usage Example
```
=== Student Portal ===
1. Login
2. View Profile
3. Dashboard
4. Settings
5. Exit
Enter your choice (1-5): 1
Redirecting to login...
```
